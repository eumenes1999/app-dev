# 家計簿アプリ 市場調査（2026-07-11）

練習台として作った家計簿アプリの、今後の機能拡張の方向づけ用メモ。

## 大手・人気どころ

| アプリ | 特徴 |
|---|---|
| マネーフォワード ME | 圧倒的知名度の最大手。銀行・カード2,400社以上連携、個人事業主・投資家向け機能もあり守備範囲が広い |
| Zaim | マネーフォワードと並ぶ老舗。レシート読み取りに強い |
| おカネレコ | 利用者500万人超。金額入力＋カテゴリ選択だけのシンプルさで初心者に強い |
| 家計簿レシーピ！ | レシート読み取り特化、ランキング常連 |

## ニッチ・特化型

| アプリ | 特徴 |
|---|---|
| 袋分家計簿（Funeasy Soft） | 給料日を締め日に設定し、費目ごとに"袋"へ配分する予算管理特化型。レシート入力の手間なし |
| OsidOri（オシドリ） | カップル・夫婦向け。個人ページと共有ページを1タップで切り替え、プライバシーを保ったまま家計を見える化 |
| ファミリーバンク | 夫婦・家族向けの完全無料な共同口座＋家計簿。共有前提で口座機能寄り |
| Moneytree | 資産管理・投資口座連携に強い高機能タイプ。家計簿というより資産全体の可視化ツール |
| 楽天家計簿 | 楽天経済圏ユーザー特化。ポイント連携が売り |
| 2秒家計簿おカネレコ（レシートスキャン系） | ホーム画面からワンタップで記録、レシート読み取りは回数制限つき無料枠あり |

## 2026年のトレンド

- 「つける」→「整える・話し合える・見える化する」への進化
- NISA・iDeCoなど投資口座との自動連携
- ペア家計簿（パートナー・家族との共有）の増加
- AIによる支出クセ分析・節約提案

## 今回作った練習アプリへの示唆

- 現状は「食費/日用品/…の8カテゴリ＋収入」の最小構成で、思想としては**おカネレコ型**（入力ハードルを下げるシンプル路線）に近い
- 次に足すなら方向性は大きく2つ
  - **袋分家計簿型**: 月初に費目ごと予算を設定し、残額を可視化する（今の「使った額の集計」から「使える額の管理」への転換）
  - **ペア家計簿型**: 複数人でのデータ共有（この構成だとlocalStorage止まりなのでサーバー/DBが必要になり、当初の「契約不要」の前提が崩れる点に注意）
