# Webアプリ制作の基礎知識（2026-08-01）

特定のアプリに紐づかない、Webアプリ制作全般の基礎知識・進め方のメモ。「人気アプリのデザインを真似したい」という話がきっかけで、その前提として整理した。

## 制作の基本的な順番（工程）

```
① 企画・要件定義 ── 誰の、どんな困りごとを解決するか。機能を絞る
② 設計          ── 画面設計（何をどこに置くか）＋データ設計（何を保存するか）
③ 技術選定       ── フロント/バック/ホスティングを何にするか
④ 実装          ── 実際にコードを書く
⑤ テスト・デバッグ ── ブラウザで動かして確認
⑥ デプロイ・公開   ── 世に出す
⑦ 運用・改善     ── 使ってみて直す、を繰り返す
```

家計簿アプリ・100日週間トラッカーの制作は、結果的にこの工程をなぞっている：
- ①＝練習台として作ろうと決めた段階、市場調査で機能を絞った段階
- ③＝Supabaseを使うと決めた段階（[Supabase無料枠運用ルール](Supabase無料枠運用ルール_2026-08-01.md)参照）
- ④⑤＝これまでの実装作業

## Webアプリの基礎構造（技術面）

フロントエンドは3層で考えるとシンプルになる。

| 層 | 役割 | 対応するファイル |
|---|---|---|
| HTML | 骨格・中身（何がそこにあるか） | `index.html` |
| CSS | 見た目（色・余白・配置） | `styles.css` |
| JS | 動き・データのやり取り | `app.js` |

データの持ち方は大きく2択：
- **端末内だけ（localStorage）** — サーバー不要。複数端末で共有できない
- **サーバー側（Supabaseなど）** — 複数端末・複数人で共有できる。ただし認証・DB設計が要る

## デザインの基礎要素（5分解）

デザインを分析・模倣する際は、以下の5要素に言語化して分解すると扱いやすい。

| 要素 | 見るポイント |
|---|---|
| カラーパレット | メインカラー・背景色・アクセントカラーが何色で、どういう比率で使われているか |
| タイポグラフィ | フォントの種類、見出しと本文のサイズ差、太さの使い分け |
| スペーシング（余白） | 要素同士の間隔にリズム（4px単位、8px単位など）があるか |
| レイアウト/グリッド | 何カラムか、カードの並べ方、画面の余白の取り方 |
| コンポーネント | ボタン・カード・入力欄など、繰り返し使われる部品の見た目の一貫性 |

## デザインを参考にする際の原則

人気アプリのデザインを真似る際は、ピクセル単位で丸ごとコピーするのではなく、**上記5要素を言語化して抽出し、自分のアプリの中身に当てはめ直す**というやり方を取る。理由は2つ：
- 丸ごとコピーは著作権的にグレー
- 「なぜそのデザインが良いのか」を学べないまま終わってしまい、次に応用が効かない
